## What Schøyen / Dumbrill claim the tablet is
From the [Schøyen catalogue entry](https://www.schoyencollection.com/music-notation/old-babylonia-cuneiform-notation/oldest-known-music-notation-ms-5105):

- Lenticular school tablet, **two double columns**, each **7 ruled lines of numbers**
- Headings: **“intonation”** and **“incantation”**
- Interpreted as **two ascending consecutive heptatonic scales**
- For a **4-string lute** tuned in **ascending fifths: C – G – D – A**
- Using **frets** (tonal/semitonal values calculated)

Full formal publication was listed as forthcoming by Dumbrill; the exact wedge-by-wedge number grid is **not** available as open ATF in this project’s CDLI dump.

## What this MIDI contains
File: `P254173_MS5105_reconstruction.mid`

1. **Open strings** C3–G3–D4–A4 (fifths tuning demo)  
2. **Scale A (“intonation”)** — ascending + descending heptatonic from C (C major intervals)  
3. **Scale B (“consecutive”)** — ascending + descending heptatonic from D in the same diatonic collection (D E F G A B♭ C D)  
4. Closing open-string arpeggio + low C  

Rhythm is **modern equal values** (the tablet is not known to encode Western meter).  
Pitch letters (C/D/…) are **modern labels** for intervals, not Babylonian pitch names.

## What it is *not*
- Not Hurrian Hymn h.6 (different tablet, Ugarit)
